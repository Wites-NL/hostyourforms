08Hosted · in voorbereiding

Liever niets installeren?

We werken aan een hosted versie. Je koppelt je eigen mailprovider in een dashboard en krijgt meteen een formulieradres. Het versturen blijft via jouw provider, vanaf jouw domein.

  • 1
    Koppel je providerPostmark, Amazon SES of Emailit, met een key die alleen mag versturen.
  • 2
    Maak formulieren in het dashboardOntvangers, toegestane websites en spamcontroles, zonder configbestand.
  • 3
    Plak het adres in je formulierDezelfde motor als de open source versie, gehost in de EU.

Zelf hosten blijft altijd mogelijk en gratis onder AGPL-3.0.

09FAQ

Vragen, beantwoord.

Nog een vraag?

De README in de repository beschrijft elke optie, met voorbeelden voor elke provider.

Naar installeren
Heb ik JavaScript nodig op mijn website?

Nee. Een gewoon HTML-formulier werkt, en de bezoeker gaat daarna naar je bedankpagina. Wil je op de pagina blijven, dan gebruik je fetch en krijg je JSON terug.

Kan ik meerdere websites en formulieren gebruiken?

Ja. Elk formulier krijgt een eigen adres, zoals /f/contact of /f/vacature, met eigen ontvangers, provider en toegestane websites.

Worden inzendingen opgeslagen?

Nee. HostYourForms controleert de inzending en geeft die door aan je mailprovider. Er staat niets in een database.

Wat als mijn provider een fout geeft?

De bezoeker krijgt een duidelijke melding of gaat naar je foutpagina met de code send_failed. De fout van de provider staat in je logs.

Moet het van-adres op mijn eigen domein staan?

Ja. Je provider verstuurt alleen vanaf domeinen die je daar hebt geverifieerd. Daardoor komen je mails ook goed aan.

Is HostYourForms open source?

Ja, onder de AGPL-3.0. Je mag het gratis gebruiken, aanpassen en zelf hosten. Bied je een aangepaste versie aan als dienst voor anderen, dan deel je ook die broncode.

Wat is het verschil met de hosted versie?

Het is dezelfde motor. Bij de hosted versie draaien wij de server en beheer je formulieren in een dashboard. Je mail gaat nog steeds via je eigen provider. Die versie is nog in voorbereiding.
